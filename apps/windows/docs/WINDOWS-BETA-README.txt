Cuelet 0.1.0-beta.1 — Windows x64

This is a portable beta for 64-bit Windows 10 version 1809 or later. Extract
the ZIP and run Cuelet.exe from the extracted folder.

For virtual microphone functionality, install VB-CABLE separately from
VB-Audio and follow the vendor's installation and restart instructions. Cuelet
does not redistribute VB-CABLE.

This beta binary is unsigned. Windows and SmartScreen may warn when Cuelet is
launched. Do not disable Windows security globally to run this beta.
