# Linux Screenshot Index

These screenshots were rendered by the native GTK4/libadwaita application
under the active GNOME Wayland session. They use generated temporary audio
fixtures and an isolated XDG configuration directory; no personal library
paths or media are shown.

The Linux captures are intentionally separate from the Windows reference
screenshots in this documentation set.
